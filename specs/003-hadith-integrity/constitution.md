# Constitution — Hadith Integrity & Reference Honesty

1. **Source Truthfulness:** Never invent, paraphrase, or LLM-synthesize Hadith Arabic matn, sanad, translations, chapter names, or scholarly grades.
2. **Canonical Arabic Preservation:** Store and display canonical Arabic matn byte-for-byte with original harakat/tashkeel. Normalization for search belongs strictly in FTS5 index columns (`text_arabic_normalized`).
3. **Explicit Numbering Schemes:** Internal row IDs (`id`, `stable_id`), canonical Sunnah.com references (`scheme_id = "sunnah"`), Muslim continuous ordinals (`"sunnah_ordinal"`), and `gadingnst` archive ordinals (`"archive_gading"`) are distinct namespaces. Never silently alias or fall back across schemes.
4. **Attributed Multi-Authority Grading:** Store and render grades with their explicit scholarly authority (`{authority, grade}`). Never collapse differing verdicts into an unqualified universal grade.
5. **Honest Availability & Error States:** Distinguish `NOT_INSTALLED`, `CORRUPT`, `PARTIAL`, `REFERENCE_UNMAPPED`, `RECORD_MISSING`, and `NO_MATCH`. Incomplete local bundles report `PARTIAL` rather than falsely declaring a reference nonexistent. Missing Indonesian translations are labeled *"Terjemahan Indonesia belum tersedia pada sumber ini"* while displaying verified English/Arabic source texts; missing English translations leave English hidden rather than fabricating text.
6. **Zero User Data Loss:** Room migrations (`v14 -> v15 -> v16`) and corpus upgrades must be additive, transactional, and preserve all existing Quran/Hadith bookmarks, reading markers, last-read state, preferences, and chat history.
7. **License Compliance:** Bundle only verified open-licensed datasets (`fawazahmed0/hadith-api` Unlicense for 7 Sunnah.com collections + `irsyadulibad/hadits-database` MIT verified 100% against `gadingnst/hadith-api` MIT for complete `ahmad` 26,363 & `darimi` 3,367). Never bundle CC-BY-NC-SA or unverified/scraped prose (`reference2`, proprietary translations). Pure factual edition concordance integers may map verified classical numbering systems (`ar_risalah` <-> `al_alamiyah`) strictly when verified by sanad+matn agreement.
