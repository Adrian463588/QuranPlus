# Clarifications & Source Licensing Decisions

1. **Canonical Corpus Source:** `fawazahmed0/hadith-api` at pinned commit `df57907be35291c91ad6a6691180e22ca9920784` (`Unlicense` public domain). Provides 7 canonical Sunnah.com collections (`bukhari`, `muslim`, `abudawud`, `tirmidhi`, `nasai`, `ibnmajah`, `malik`) with Arabic, English, Indonesian (partial), chapters, references, and scholarly grades.
2. **Musnad Ahmad & Sunan ad-Darimi Complete Open Source (`ahmad`, `darimi`):** `irsyadulibad/hadits-database` (`MIT`, verified 4,305/4,305 for `ahmad` and 2,949/2,949 for `darimi` identical against `gadingnst/hadith-api` at pinned commit `8e15b4f9e7585822426a0d470e8dfec27e2a1707`) supplies the complete `26,363`-record `Musnad Ahmad` (`1..26,363`) and `3,367`-record `Sunan ad-Darimi` (`1..3,367`) offline. Both are bundled cleanly inside `sunnah-canonical-bundle.zip` (`65,716` total active hadiths across all 9 Kutubut Tis'ah collections), preventing `gadingnst`'s 84%-partial `ahmad` omission (`4,305` sparse records missing `#3800` and `#4001`) from blocking offline lookups.
3. **Musnad Ahmad Numbering Schemes (`ar_risalah` vs `archive_gading`):**
   - `ar_risalah` (**default on `Musnad Ahmad`**): Mu'assasah Ar-Risalah numbering (`1..27,647`, tahqiq Shu'ayb al-Arna'ut, matching `https://hadits.net/ahmad:4001`). Under this scheme, **`4001`** resolves strictly to the Abdullah bin Mas'ud *li'an* narration (`Al-Alamiyah #3800`, `Shu'ayb al-Arna'ut: Isnaduhu Sahih`, Ar-Risalah 7/105). Unaligned repeated *mutaba'ah* sub-chains (`1..27,647`) are preserved explicitly as unmapped edition variance rather than forced or substituted.
   - `archive_gading`: Al-Alamiyah / Lidwa numbering (`1..26,363`), used by legacy bookmarks/markers (`schemeId = null`) and optional toggle. Under this scheme, **`4001`** resolves strictly to the Abdullah bin Mas'ud narration on reliance upon Allah during poverty (`مَنْ نَزَلَتْ بِهِ فَاقَةٌ`), and **`3800`** resolves to *li'an*.
   - Upstream discrepancy warning verified: `islamtics.com/hadith/musnad-ahmad/4001/` mixes Ar-Risalah `#4001` Arabic with English text belonging to Ar-Risalah `#4027` (`Al-Alamiyah #3823`, *"moths or flies"*); excluded to prevent Arabic/translation mismatch.
4. **Excluded Dataset:** `docs/HadistReference/reference2` (`hadith-json`, ISC) is excluded from APK bundling due to sequential `idInBook` mismatching Sunnah.com numbers and unverified Sunnah.com scraping redistribution status.
5. **Default Numbering Scheme per Collection:** `"sunnah"` is default for the 7 Sunnah.com collections (`bukhari`, `muslim`, `abudawud`, `tirmidhi`, `nasai`, `ibnmajah`, `malik`); `"ar_risalah"` is default for `ahmad`; `"archive_gading"` is default for `darimi` and legacy bookmarks/markers without `schemeId`.
6. **Missing Translations:** Missing Indonesian is labeled *"Terjemahan Indonesia belum tersedia pada sumber ini"* with verified English (`translation_en`). On MIT `ahmad`/`darimi`, complete verified Arabic + Indonesian is displayed without fabricating English.
7. **Sahih Muslim Variants:** `arabicnumber` (`2723.01`, `2723.02`, ...) maps to `scheme_id = "sunnah"`, `reference_number = 2723`, `variant_suffix = "01"` / `"02"`, while continuous `hadithnumber` (`6907`, `6908`) is stored under `scheme_id = "sunnah_ordinal"` so neither collides nor gets confused.
8. **Display Count vs Reference Range:** UI always displays verified `active_record_count` separately from per-scheme `min_reference_number..max_reference_number`, never assuming `count == maxReferenceNumber`.
9. **Target Device:** Physical `SM-G988B` (`RRCN3008VYE`) connected via ADB with active user database (`v15`) and SAF folder `/sdcard/QuranPlus`.
